JavaScript 类与继承

1. class 基础

定义类

class Person {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }
    introduce() {
        return `我是${this.name}，${this.age}岁`;
    }
}
const p = new Person("张三", 18);
p.introduce();

说明：constructor在new时自动调用；方法写在类里，所有实例共享

静态方法

class MathUtil {
    static square(n) { return n * n; }
}
MathUtil.square(5);  // 25

说明：static方法属于类本身，通过类名调用，不能通过实例调用

getter 与 setter

class Circle {
    constructor(r) { this.r = r; }
    get area() { return Math.PI * this.r ** 2; }
    set radius(v) { this.r = v; }
}

说明：getter像属性一样读取，setter像属性一样赋值，可以在其中加入计算或校验

私有字段

class Wallet {
    #balance = 0;
    add(n) { this.#balance += n; }
    get balance() { return this.#balance; }
}

说明：以#开头的字段是真正的私有，类外部访问会直接报语法错误

2. 继承

extends 与 super

class Student extends Person {
    constructor(name, age, school) {
        super(name, age);
        this.school = school;
    }
    introduce() {
        return super.introduce() + `，就读于${this.school}`;
    }
}

说明：extends继承父类；子类构造函数必须先调用super()再使用this；super.方法()调用父类方法

instanceof 判断

const s = new Student("李四", 20, "某大学");
s instanceof Student;  // true
s instanceof Person;   // true

说明：instanceof检查对象的原型链上是否有该类的原型

3. 原型链

class 的本质

typeof Person;                                  // "function"
Object.getPrototypeOf(p) === Person.prototype;  // true

说明：class是原型继承的语法糖，方法实际存放在Person.prototype上，属性查找沿原型链向上
