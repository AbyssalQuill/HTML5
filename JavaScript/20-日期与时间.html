JavaScript 日期与时间

1. 创建日期

常见创建方式

new Date();                          // 当前时间
new Date("2024-03-15");              // 字符串
new Date(2024, 2, 15, 10, 30);       // 年、月、日、时、分
new Date(1710000000000);             // 毫秒时间戳

说明：注意月份从0开始，2代表3月；日期字符串建议使用ISO格式（YYYY-MM-DD）

时间戳

Date.now();
new Date().getTime();

说明：时间戳是1970年1月1日UTC起的毫秒数，适合计算时间差和比较先后

2. 读取与设置

get 方法

const d = new Date(2024, 2, 15, 10, 30);
d.getFullYear();  // 2024
d.getMonth();     // 2（3月）
d.getDate();      // 15（几号）
d.getDay();       // 5（星期，0是周日）
d.getHours();     // 10

说明：getDate是几号，getDay是星期几，两者不要混淆；对应的set方法可修改各部分

日期计算

const d2 = new Date(2024, 0, 31);
d2.setDate(d2.getDate() + 1);  // 2月1日

说明：设置的值超出范围时会自动进位，用来做“加几天”很方便

计算时间差

const diff = new Date("2024-12-25") - new Date("2024-12-01");
diff / (1000 * 60 * 60 * 24);  // 24天

说明：两个Date相减得到毫秒差，再换算成需要的单位

3. 格式化输出

toLocaleString

d.toLocaleDateString("zh-CN");
d.toLocaleTimeString("zh-CN");
d.toLocaleString("zh-CN", { hour12: false });

说明：按地区习惯输出日期时间，无需手动拼接字符串

Intl.DateTimeFormat

new Intl.DateTimeFormat("zh-CN", {
    year: "numeric", month: "long", day: "numeric", weekday: "long"
}).format(d);

说明：通过选项精确控制输出的格式，如“2024年3月15日星期五”

toISOString

d.toISOString();  // "2024-03-15T02:30:00.000Z"

说明：输出UTC时间的标准格式，适合与服务器交互；本地显示用toLocale系列方法
