JavaScript fetch与JSON

1. JSON

对象转字符串

const user = { name: "张三", age: 18 };
const text = JSON.stringify(user);
// '{"name":"张三","age":18}'

说明：JSON.stringify把JavaScript值转成JSON字符串，用于存储和传输

字符串转对象

const obj = JSON.parse('{"name":"张三","age":18}');
obj.name;  // "张三"

说明：JSON.parse把JSON字符串还原成对象，格式不合法会抛出异常，需要try-catch

格式化输出

JSON.stringify(user, null, 2);

说明：第三个参数是缩进空格数，便于阅读；第二个参数可以是数组，用来只保留指定的属性

JSON 的限制

JSON.stringify({ a: undefined, b: () => 1, c: NaN });
// '{"c":null}'

说明：undefined和函数会被丢弃，NaN变成null；key必须使用双引号，不能有注释和末尾逗号

2. fetch 请求

GET 请求

fetch("https://api.example.com/users/1")
    .then(res => res.json())
    .then(data => console.log(data));

说明：fetch返回Promise；res.json()读取并解析响应体，它本身也返回Promise

async/await 写法

async function getUser() {
    const res = await fetch("https://api.example.com/users/1");
    if (!res.ok) {
        throw new Error("请求失败：" + res.status);
    }
    return await res.json();
}

说明：fetch只在网络故障时才reject，404、500等状态码不会报错，必须自己检查res.ok

POST 请求

fetch("https://api.example.com/users", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ name: "张三" })
});

说明：通过第二个参数设置method、headers和body；发送JSON时要声明Content-Type并先序列化
