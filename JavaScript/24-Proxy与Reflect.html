JavaScript Proxy与Reflect

1. Proxy 代理

基本用法

const target = { name: "张三" };
const proxy = new Proxy(target, {
    get(obj, key) {
        console.log("读取", key);
        return obj[key];
    },
    set(obj, key, value) {
        console.log("设置", key, value);
        obj[key] = value;
        return true;
    }
});

说明：Proxy包装一个对象，并通过handler拦截读取、赋值、删除等操作

数据校验

const person = new Proxy({}, {
    set(obj, key, value) {
        if (key === "age" && typeof value !== "number") {
            throw new TypeError("age必须是数字");
        }
        obj[key] = value;
        return true;
    }
});

说明：在set拦截器中校验数据，不合法就抛出错误，对象的使用者无需改变写法

默认值

const withDefault = new Proxy({}, {
    get(obj, key) { return key in obj ? obj[key] : 0; }
});

说明：读取不存在的属性时返回默认值，常用于计数器等场景

2. Reflect

与Proxy配合

const logged = new Proxy(target, {
    get(obj, key, receiver) {
        return Reflect.get(obj, key, receiver);
    }
});

说明：Reflect提供与Proxy拦截器同名的方法，在拦截器里用它执行默认行为最规范

常用方法

Reflect.has(obj, "name");           // 等价于 "name" in obj
Reflect.ownKeys(obj);               // 包含Symbol键的所有自有键
Reflect.deleteProperty(obj, "age"); // 等价于 delete obj.age

说明：Reflect把原本分散的操作符和Object方法统一成函数，返回布尔值而不是抛错
