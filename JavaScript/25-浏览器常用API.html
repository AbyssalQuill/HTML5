JavaScript 浏览器常用API

1. URL 与查询参数

解析URL

const url = new URL("https://example.com/search?q=js&page=2#top");
url.hostname;  // "example.com"
url.pathname;  // "/search"
url.hash;      // "#top"

说明：URL对象把网址拆成各个部分，比自己用字符串截取可靠

URLSearchParams

const params = new URLSearchParams("q=js&page=2");
params.get("q");          // "js"
params.set("page", "3");
params.toString();        // "q=js&page=3"

说明：读取和构造查询字符串，会自动处理编码

2. 观察器

IntersectionObserver

const io = new IntersectionObserver((entries) => {
    entries.forEach(e => console.log(e.isIntersecting));
});
io.observe(element);

说明：监听元素是否进入视口，用于图片懒加载、无限滚动、滚动到某处触发动画，比监听scroll事件性能好

ResizeObserver

new ResizeObserver((entries) => {
    console.log(entries[0].contentRect.width);
}).observe(element);

说明：元素尺寸变化时触发回调，可用于组件自适应

3. 其他实用API

structuredClone 深拷贝

const copy = structuredClone({ a: [1, 2], d: new Date() });

说明：深拷贝对象，支持Date、Map、Set等，不能拷贝函数；比JSON.parse(JSON.stringify())更可靠

matchMedia 媒体查询

window.matchMedia("(prefers-color-scheme: dark)").matches;

说明：在JavaScript里判断媒体查询是否匹配，如是否暗色模式、屏幕宽度

剪贴板

await navigator.clipboard.writeText("要复制的文字");

说明：需要在HTTPS或localhost下，并且通常由用户操作（如点击）触发

requestAnimationFrame

function step() {
    // 更新动画
    requestAnimationFrame(step);
}
requestAnimationFrame(step);

说明：让浏览器在下一次重绘前调用回调，做动画比setTimeout更流畅，页面不可见时会自动暂停
