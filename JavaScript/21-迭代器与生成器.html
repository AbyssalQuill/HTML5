JavaScript 迭代器与生成器

1. 迭代器

可迭代对象

const arr = [10, 20, 30];
const it = arr[Symbol.iterator]();
it.next();  // { value: 10, done: false }
it.next();  // { value: 20, done: false }

说明：数组、字符串、Map、Set等都是可迭代对象，for...of、展开运算符都依赖这套协议

自定义迭代器

const range = {
    from: 1, to: 3,
    [Symbol.iterator]() {
        let cur = this.from, end = this.to;
        return {
            next: () => cur <= end
                ? { value: cur++, done: false }
                : { value: undefined, done: true }
        };
    }
};
[...range];  // [1, 2, 3]

说明：只要对象有[Symbol.iterator]方法，并返回带next()的对象，就可以被for...of遍历

2. 生成器

function* 与 yield

function* gen() {
    yield 1;
    yield 2;
    return 3;
}
const g = gen();
g.next();  // { value: 1, done: false }
g.next();  // { value: 2, done: false }
g.next();  // { value: 3, done: true }

说明：生成器函数调用后不会立即执行，每次next()运行到下一个yield暂停，状态自动保存

用生成器简化迭代器

const range2 = {
    from: 1, to: 3,
    *[Symbol.iterator]() {
        for (let i = this.from; i <= this.to; i++) yield i;
    }
};

说明：用*[Symbol.iterator]写法，几行代码即可替代手写的迭代器对象

无限序列

function* naturals() {
    let n = 1;
    while (true) yield n++;
}

说明：生成器是惰性的，只在需要时才计算，所以可以表示无限序列，使用时用break或手动取前几个

yield* 委托

function* both() {
    yield* [1, 2];
    yield* "ab";
}
[...both()];  // [1, 2, "a", "b"]

说明：yield*把迭代委托给另一个可迭代对象
