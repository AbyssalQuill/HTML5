JavaScript Map与Set

1. Map

创建与读写

const map = new Map();
map.set("name", "张三");
map.set(1, "数字键");
map.get("name");   // "张三"
map.has(1);        // true
map.size;          // 2
map.delete(1);

说明：Map是键值对集合，与普通对象不同，键可以是任意类型，并且会记住插入顺序

遍历

for (const [key, value] of map) {
    console.log(key, value);
}
map.forEach((value, key) => console.log(key, value));

说明：Map可以直接用for...of遍历，每一项是[键, 值]数组，也可使用keys()、values()、entries()

初始化与转换

const m = new Map([["a", 1], ["b", 2]]);
Object.fromEntries(m);           // { a: 1, b: 2 }
new Map(Object.entries({ x: 1 }));

说明：Map可以由二维数组创建，并且能与对象通过entries和fromEntries互相转换

2. Set

创建与去重

const set = new Set([1, 2, 2, 3, 3]);
set.size;           // 3
[...set];           // [1, 2, 3]

说明：Set是不重复值的集合，最常见用途是给数组去重

常用方法

set.add(4);
set.has(2);     // true
set.delete(1);
set.clear();

说明：add添加、has判断、delete删除、clear清空；重复add同一个值不会有变化

集合运算

const a = new Set([1, 2, 3]);
const b = new Set([2, 3, 4]);
[...a].filter(x => b.has(x));         // 交集 [2, 3]
new Set([...a, ...b]);                 // 并集
[...a].filter(x => !b.has(x));        // 差集 [1]

说明：借助展开运算符和filter可以方便地实现交集、并集、差集

3. WeakMap 与 WeakSet

弱引用

const cache = new WeakMap();
let obj = { id: 1 };
cache.set(obj, "附加数据");
obj = null;  // 对象可被垃圾回收

说明：WeakMap的键必须是对象且是弱引用，不阻止垃圾回收，适合给对象附加数据而不造成内存泄漏；不能遍历，没有size
