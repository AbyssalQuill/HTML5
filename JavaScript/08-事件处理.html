JavaScript 事件处理

1. 常见事件类型

鼠标事件

// click - 点击事件
<button onclick="handleClick()">点击我</button>

// mouseover/mouseout - 鼠标移入移出
<div onmouseover="handleMouseOver()" onmouseout="handleMouseOut()">
    悬停区域
</div>

说明：处理用户的鼠标交互操作

键盘事件

// keydown - 按键按下
<input type="text" onkeydown="handleKeyDown(event)">

// keyup - 按键释放
<input type="text" onkeyup="handleKeyUp(event)">

说明：处理用户的键盘输入操作

表单事件

// submit - 表单提交
<form onsubmit="return handleSubmit()">
    <input type="text">
    <button type="submit">提交</button>
</form>

// change - 值改变
<input type="checkbox" onchange="handleChange(this)">

说明：处理表单相关的用户操作

2. 事件对象

获取事件信息

function handleClick(event) {
    console.log("事件类型:", event.type);
    console.log("目标元素:", event.target);
    console.log("坐标位置:", event.clientX, event.clientY);
}

说明：event对象包含事件的详细信息

阻止默认行为

function handleSubmit(event) {
    event.preventDefault(); // 阻止表单默认提交
    alert("自定义提交逻辑");
}

说明：使用preventDefault()阻止元素的默认行为

3. 事件监听器（推荐方式）

addEventListener

// 给元素添加事件监听器
document.getElementById("myButton").addEventListener("click", function() {
    console.log("按钮被点击了!");
});

// 移除事件监听器
element.removeEventListener("click", handler);

说明：现代JavaScript推荐使用addEventListener方法

箭头函数作为监听器

const button = document.getElementById("myButton");
button.addEventListener("click", () => {
    console.log("使用箭头函数的监听器");
});

说明：箭头函数可以简化代码，但注意this指向问题

4. 实际应用示例

计数器应用

let count = 0;
function incrementCounter() {
    count++;
    document.getElementById("counter").textContent = count;
}

说明：点击按钮增加计数器的值

显示/隐藏内容

function toggleVisibility() {
    let content = document.getElementById("content");
    if (content.style.display === "none") {
        content.style.display = "block";
    } else {
        content.style.display = "none";
    }
}

说明：点击切换内容的显示和隐藏状态
