JavaScript 闭包与this

1. 闭包

什么是闭包

function createCounter() {
    let count = 0;
    return function () {
        count++;
        return count;
    };
}
const counter = createCounter();
counter();  // 1
counter();  // 2

说明：内部函数可以访问外部函数的变量，即使外部函数已经执行完毕，这个组合就是闭包

闭包的私有变量

function createAccount(balance) {
    return {
        deposit(n) { balance += n; return balance; },
        getBalance() { return balance; }
    };
}
const account = createAccount(100);
account.deposit(50);  // 150
account.balance;      // undefined

说明：外部无法直接访问balance，只能通过返回的方法操作，实现数据私有

循环中的闭包陷阱

for (var i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 0);  // 3 3 3
}
for (let j = 0; j < 3; j++) {
    setTimeout(() => console.log(j), 0);  // 0 1 2
}

说明：var没有块级作用域，三个回调共享同一个i；let每次循环创建新的绑定

2. this 指向

对象方法中的this

const user = {
    name: "张三",
    sayHi() { return "你好，" + this.name; }
};
user.sayHi();  // "你好，张三"

说明：作为对象方法调用时，this指向调用它的对象

丢失this

const fn = user.sayHi;
fn();  // this不再是user

说明：把方法赋给变量后单独调用，this不再指向原对象（严格模式下是undefined）

箭头函数的this

const timer = {
    seconds: 0,
    start() {
        setInterval(() => { this.seconds++; }, 1000);
    }
};

说明：箭头函数没有自己的this，沿用外层的this，适合回调；不要用箭头函数写对象方法

call、apply、bind

function greet(greeting) {
    return greeting + "，" + this.name;
}
greet.call({ name: "李四" }, "你好");
greet.apply({ name: "王五" }, ["早上好"]);
const bound = greet.bind({ name: "赵六" });
bound("晚上好");

说明：call和apply立即调用并指定this（参数分别是逐个传和数组传）；bind返回一个绑定了this的新函数
