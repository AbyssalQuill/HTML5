JavaScript 综合项目：待办清单

1. 功能说明

涉及的知识点

  • DOM操作：创建、添加、删除元素
  • 事件处理：表单提交、点击、事件委托
  • 数组方法：push、filter、map
  • 本地存储：localStorage保存数据
  • JSON：序列化与解析

说明：这个小项目把前面学过的知识串起来，刷新页面后数据依然保留

2. 待办清单

    共0项，已完成0项

    说明：点击文字切换完成状态，点击删除按钮移除事项

    3. 实现思路

    1. 数据用数组保存

    let todos = JSON.parse(localStorage.getItem("todos") || "[]");

    说明：每一项是{ id, text, done }对象；读取不到时使用空数组

    2. 数据变化后统一重新渲染

    function update() {
    localStorage.setItem("todos", JSON.stringify(todos));
    render();
}

    说明：任何增删改都先改数组，再保存并重绘，数据和界面始终一致

    3. 事件委托

    list.addEventListener("click", (e) => { /* 通过e.target判断点击对象 */ });

    说明：在父元素上统一监听，新增的子元素不需要重复绑定事件

    4. 防止XSS

    li.textContent = item.text;  // 不要使用innerHTML

    说明：用户输入的内容要用textContent写入页面，避免被当作HTML执行
