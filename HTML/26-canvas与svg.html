HTML5canvas与svg

1. canvas 画布

绘制矩形

您的浏览器不支持canvas 
const ctx = canvas.getContext("2d");
ctx.fillStyle = "#4361ee";
ctx.fillRect(20, 20, 120, 80);
ctx.strokeRect(160, 20, 120, 80);

说明：先getContext("2d")获得画笔，再用fillRect填充、strokeRect描边；width和height要写在属性里，用CSS缩放会变形

绘制路径与圆

ctx.beginPath();
ctx.arc(150, 60, 40, 0, Math.PI * 2);
ctx.fill();

说明：beginPath开始路径，arc画圆弧（圆心x、y，半径，起止弧度），再fill或stroke绘制

绘制文字

ctx.font = "24px sans-serif";
ctx.fillText("Hello Canvas", 20, 50);

说明：canvas是位图，画完后无法选中单个图形；适合游戏、图表、图像处理等需要大量绘制的场景

2. svg 矢量图

基本图形

<svg width="300" height="120">
    <rect x="20" y="20" width="100" height="80" fill="#4361ee"></rect>
    <circle cx="190" cy="60" r="40" fill="#ef476f"></circle>
</svg>

说明：svg用标签描述图形，rect矩形、circle圆、line线、text文字、path路径，放大不失真

viewBox 缩放

说明：viewBox定义内部坐标系，width和height决定显示大小，二者不同时图形会自动缩放，适合做自适应图标

svg 文字

说明：svg里的文字仍然是文本，可被选中、搜索和复制

3. 如何选择

对比

  • svg：图形数量少、需要缩放清晰、需要鼠标交互和CSS样式（图标、示意图）
  • canvas：图形数量大、需要频繁重绘（游戏、动画、数据可视化大数据量）

说明：svg每个图形都是DOM节点，数量多了会变慢；canvas只有一块像素，性能稳定但需要自己管理交互
