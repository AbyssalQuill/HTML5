HTML5head与meta标签

1. head 中的基础信息

字符编码 charset

<meta charset="UTF-8">

说明：声明文档编码，必须放在head最前面（前1024字节内），否则中文可能乱码

视口 viewport

<meta name="viewport" content="width=device-width, initial-scale=1.0">

说明：让移动端按设备宽度渲染，是响应式设计的前提，缺少它页面会被当作桌面宽度缩小显示

页面标题 title

<title>页面标题 - 站点名</title>

说明：显示在标签页和搜索结果中，每个页面应唯一且简明，建议60字符以内

2. SEO 相关

页面描述 description

<meta name="description" content="一句话介绍页面内容">

说明：搜索引擎常把它显示在结果摘要里，建议控制在150字符以内

控制搜索引擎抓取 robots

<meta name="robots" content="noindex, nofollow">

说明：noindex不让收录，nofollow不跟踪页面内链接；默认是允许收录

规范链接 canonical

<link rel="canonical" href="https://example.com/page">

说明：同一内容有多个网址时，告诉搜索引擎哪个是主地址，避免重复内容

3. 社交分享与图标

Open Graph

<meta property="og:title" content="标题">
<meta property="og:description" content="描述">
<meta property="og:image" content="https://example.com/cover.jpg">
<meta property="og:url" content="https://example.com/page">

说明：链接被分享到微信、微博、社交平台时，用来决定卡片显示的标题、描述和封面图

网站图标 favicon

<link rel="icon" href="/favicon.ico">

说明：显示在浏览器标签页的小图标

主题色 theme-color

<meta name="theme-color" content="#4361ee">

说明：移动端浏览器据此给地址栏等界面着色

4. 加载资源

link 引入样式与预加载

<link rel="stylesheet" href="style.css">
<link rel="preload" href="font.woff2" as="font" crossorigin>
<link rel="dns-prefetch" href="//cdn.example.com">

说明：preload提前加载关键资源，dns-prefetch提前解析域名，用于优化加载速度

script 的 defer 与 async

<script src="app.js" defer></script>
<script src="stat.js" async></script>

说明：defer等页面解析完再按顺序执行；async下载完立刻执行，顺序不定，适合独立脚本如统计
