CSS层叠与优先级

1. 后者覆盖前者

样式相同优先级时，后写的生效（这行是绿色）

说明：优先级相同，样式表中靠后的规则覆盖靠前的

2. 选择器权重

id选择器权重高于class（这行是红色）

说明：权重大小：内联样式 > id > class/属性/伪类 > 标签/伪元素 > 通配符

3. 权重计算

  • 内联样式：1,0,0,0
  • id选择器：0,1,0,0
  • class、属性、伪类：0,0,1,0
  • 标签、伪元素：0,0,0,1

说明：按位比较，高位大者胜出，不会进位；例如div.a.b（0,0,2,1）大于div p span a（0,0,0,4）

4. 内联样式

内联样式覆盖外部样式（这行是紫色）

说明：行内style权重很高，但难以维护，不推荐大量使用

5. !important

!important压过内联样式（这行是橙色）

说明：!important会无视权重，仅在覆盖第三方样式等特殊场景使用，滥用会让样式难以维护

6. 继承

子元素继承了父元素的文字颜色和字体大小

说明：color、font-*、line-height等文本属性会继承；border、margin、padding、background不会继承

7. 控制继承

inherit/initial/unset可显式控制（这行恢复默认颜色）

说明：inherit强制继承，initial重置为初始值，unset表示能继承则继承、否则重置

8. 样式来源顺序

说明：浏览器默认样式 < 用户样式 < 作者样式；加上!important后顺序反过来。编写时尽量用class，保持低权重
