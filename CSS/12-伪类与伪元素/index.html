CSS伪类与伪元素

1. 链接状态伪类

鼠标悬停和点击试试

说明：:link未访问、:visited已访问、:hover悬停、:active按下，书写顺序建议LVHA

2. 表单状态伪类

说明：:focus聚焦、:disabled禁用、:read-only只读、:checked选中、:required必填

3. 结构伪类

  • 第1项
  • 第2项
  • 第3项
  • 第4项
  • 第5项

说明：:first-child首个、:last-child最后一个、:nth-child(2n)偶数项、:nth-child(odd)奇数项

4. 否定伪类 :not()

  • 普通项
  • 被排除的项
  • 普通项

说明：:not(选择器)选中不匹配括号内选择器的元素

5. ::before 与 ::after

伪元素插入的内容

说明：::before在内容前、::after在内容后插入，必须设置content属性（可以为空字符串）

6. ::first-letter 与 ::first-line

首字下沉效果：这段文字的第一个字会被放大。伪元素可以选中文本的一部分。

说明：::first-letter选中首字符，::first-line选中第一行

7. ::placeholder 与 ::selection

用鼠标选中这段文字试试

说明：::placeholder修改占位文字样式，::selection修改选中文本的样式

8. 伪类与伪元素的区别

说明：伪类（单冒号）选择元素的某种状态；伪元素（双冒号）选择或创建元素的某个部分
